ZIP

Entropy-law data selection for reducing redundancy in instruction-tuning pools while preserving useful learning signals.

Paper PDF Code Citation

1. Paper

Mingjia Yin, Chuhan Wu, Yufei Wang, Hao Wang, Wei Guo, Yasheng Wang, Yong Liu, Ruiming Tang, Defu Lian, and Enhong Chen. Entropy Law: The Story Behind Data Compression and LLM Performance. arXiv preprint arXiv:2407.06645, 2024.

ZIP selects data by evaluating how candidates change the compressed representation of the selected pool, aiming to reduce redundancy rather than only scoring samples independently.

2. Method At A Glance

3. Usage

python ZIP.py --data_path data_pool.json --save_path selected_data.json --budget 10000

The selected file can be used by downstream alignment tools such as Axolotl, with MT-Bench evaluation available through FastChat.
